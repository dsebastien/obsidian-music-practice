# v0.19 Note names setting

Status: shipped in 0.19.0.

## Goal

A setting for how note names show: letters (C D E), solfège (Do Ré Mi) or German (C D E … H, B for B♭). From music-notation 0.16.0 (#12). It changes how names show, never how a block or a note is read or written.

## Decisions (Sébastien, 2026-11-09)

1. Scope: the diagrams the library draws, and the drills. Modal hints (Add a learning note's "Note: C Major", near matches, notices) stay in letters.
2. Note titles, properties, `drill_setting`, `drill_stats` and drill note titles stay in letters.

## Rules

- `notationLayout.naming`: `letters` (default), `solfege`, `german`; any other stored value is `letters`. Settings → Notation, dropdown "Note names".
- Render defaults: `naming` reaches the library's `naming` render option only when not letters (so letters output is unchanged), with the orientations and the hand. A block's own `naming:` line wins (the library's rule).
- A change redraws the blocks on screen, as the other layout settings do.
- Drawings the plugin makes with the library's renderers (drills, click input): drawn under `withNaming`, so string names and labels follow the setting. The click input's dot labels too.
- Drills: the question ("Find Do on string 5", "Find La♯3", "Find the notes of La minor pentatonic"), the 12 note buttons, the chord and scale choices, the feedback ("It was Do.") and the heat map's cells in the naming. Answers are compared in letters (the buttons keep letter values). The drill header (the drill note's title) and the setup form's key range (typed, read as letters) stay in letters.
- Names: a note with or without octave (`A#3` → `La♯3`; German `B` → `H`, `Bb` → `B`), chord symbols by `chordInNaming` (`Ré m7`), scale names by their root (`F# harmonic minor` → `Fa♯ harmonic minor`). Never `shownText` on whole prompts: it keeps the "A" of "Find A on string 5" as the English article.
