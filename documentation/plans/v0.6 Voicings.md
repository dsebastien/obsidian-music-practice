# v0.6: voicings

Goal: all the ways to play a chord (#54), from the notation library's voicing generator (music-notation 0.4, #18 there). Tabs and scores move to v0.7.

- **Voicings of this chord** (guitar chord notes) and **Voicings of a chord** (typed): every playable voicing, easiest first, filtered by neck area, root string, inversions and stretch; the note's own voicing marked.
- **Use for this note**: frets, fingers, shape (mapped to the type's values), position when present; only the note's own shape (or any when it has none), since mastery stays per note.
- **Add as note**: a chord note titled `<name> - <shape>` (or `at fret N`), properties filled, empty diagram block.
- **Add a learning note**: More voicings… picks one; typed frets get their fingers.
