# v0.20 Drills by ear (#91)

Status: built (branch `ear-drills`), vault-checked; not released (branch `ear-drills`).

## Goal

A note sounds; you find it on the fretboard or the keyboard. Two more kinds of the note, chord and scale drills (#73), with the same rules.

## Decisions (Sébastien, 2026-11-09)

1. Two kinds: `Fretboard by ear` and `Keyboard by ear` (the `drill_kind` values; already in the vault's guitar and piano exercise types).
2. Same rules as the sight drills: one drill note per kind and setting, the weak-spot map in `drill_stats`, 20 questions, 60 % from weak spots, a spot cleared after 3 right answers in a row under 2 s, a review on Save, new drill notes `public_note: false`.
3. Fretboard by ear: the strings and frets of Fretboard notes. Keyboard by ear: the key range of Keyboard notes (one octave by default on narrow touch screens, `drillDefaults`).
4. Right: by default the right pitch class anywhere in the range (any octave). A setting "exact octave" (off by default) makes only the same pitch right. In `drill_setting` words: `string 5, frets 0-5, exact octave`.
5. Reference note: a setting, off by default (`with a reference`). On: each question plays a reference first (keyboard C4, fretboard the lowest note of the setting), then the note. Play again and Reference buttons are always there; R replays the note.
6. Weak spots: the pitch asked, with its octave (`G3`, `F#4`), for both kinds (any place is right on a fretboard, so `s5f3` spots don't fit). A miss marks the wrong pick and every right place, as find questions do. Names follow Settings → Notation blocks → Note names.
7. With playback off (Settings → Playback), the by-ear kinds don't start: the modal says so.

## Rules

- Answer time counts from the moment the note starts sounding (after the reference), as the player reports it (`onStart`), else from the play call plus the reference's length.
- Words: `<strings>, frets a-b[, exact octave][, with a reference]`, `keys C3-B4[, exact octave][, with a reference]`. The setting's own ask (find, name) doesn't apply: a by-ear question is always a find.
- Prompt: "Find the note you hear" (never the note's name), "… (exact octave)" when exact.
