# v0.5: practice

Goal: practice with the instrument in hand: undo a log (#36), a metronome and speed trainer (#39), a practice panel (#37), chord change drills (#40), pausing the timer (#52), and commands for all of them (#53). Tabs and scores move to v0.6.

## Undo the last log (#36)

- Before writing, a log records what it changes: for each item, the old value of every frontmatter key it touches (and whether it existed); the session note it creates; the time entry it adds to the activity. Only the last log, in plugin data (survives a restart).
- Undo restores those keys (removing the ones the log added), removes its activity entry and trashes its session note. It refuses, naming the files, when a touched key changed since or the session note was edited.
- A Kanban Action Planner timer's entry (adopted timer) stays: it's real tracked time; the notice says so.
- Command, an Undo button in the notice after logging, `api.undoLastLog()`.

## Metronome and speed trainer (#39)

- Web Audio, look-ahead scheduling, synthesized clicks; BPM, beats per bar, accent on beat 1, subdivisions, volume.
- Speed trainer: from the item's current BPM (or one typed), +N BPM every M bars or on each "+", stops at the target. Save BPM writes the reached tempo with the Set BPM rules.
- In the practice panel, or a small modal without it. Settings for the defaults.

## Practice panel (#37) and pause (#52)

- Right-sidebar view: the timer (start, pause, stop), the session list (today's plan as a checklist, items added by search, mastery and BPM with −/+ nudges kept for the log), the metronome tied to the selected item, Log this session (prefilled with the timer's minutes, ticked items and BPMs; the list clears after the log). The list survives restarts (plugin data). Own tab on mobile.
- Pause: accumulated time next to the start; the status bar and Log practice count practiced minutes only.
- Plan a practice session: "Use in panel".

## Chord change drills (#40)

- One guitar exercise note per pair ("A ↔ D Change"), linking both chords through `trains`, with `changes_best` and `changes_last` (changes per minute, added to the guitar-exercises type; property names in the settings for the standalone model). An ordinary learning item; history in session notes.
- Drill: pick a pair (current-focus chords' pairs first, slowest first; a missing pair note is created), a countdown (60 s by default) with both diagrams side by side, "+1" button or space bar (or type the count), save best and last, offer to log the minute.

## Commands (#53)

Open practice panel; pause / resume timer; start / stop metronome; speed trainer for the current note; save metronome BPM to the current note; chord change drill (and for the current note); undo last practice log.
