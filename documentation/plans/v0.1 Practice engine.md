# v0.1 Practice engine

Goal: log practice in under a minute and get a useful "what next", on top of the Obsidian Starter Kit (OSK) or the plugin's own note model. No notation rendering (v0.2, needs the music notation library).

Tracking: GitHub milestone "v0.1 Practice engine" (issues #3–#12).

## Done

- Domain layer (`src/app/domain/`): mastery scale, review (light SM-2), practice score, ready to learn, unlocks, focus, practice plan, configurable rules. Pure, unit-tested (#5).
- Note model from OSK (#3, partial: standalone model #4 open), item repository, Practice next and plan modals (#8), Log practice with session note, item updates and activity time entry (#6), Tailwind styles started (#28).
