# v0.1 Practice engine

Goal: log practice in under a minute and get a useful "what next", on top of the Obsidian Starter Kit (OSK) or the plugin's own note model. No notation rendering (v0.2, needs the music notation library).

Tracking: GitHub milestone "v0.1 Practice engine" (issues #3–#12).

## Done

- Domain layer (`src/app/domain/`): mastery scale, review (light SM-2), practice score, ready to learn, unlocks, focus, practice plan. Pure, unit-tested. (#5, partially: the rules; wiring to notes pending.)

## Next

1. **Note model** (#3, #4): `NoteModelService` returning learning types, session types and field names.
    - OSK source: port of the Kanban Action Planner's `starter-kit.service.ts` (method checks, `ApiResult` unwrap, `note-types-changed`), learning types = explicit status on the mastery scale.
    - Local source: settings (kinds by tag, session folder, field names) with working defaults.
2. **Item repository**: read learning notes from the metadata cache into `LearningItemInput` (levels, priorities, review fields, BPMs, prerequisite and body links); recompute on metadata changes.
3. **Writers**: `PracticeLogService` (session note + items + activity time entry, dedup), mastery and BPM updates, review results. `processFrontMatter` only.
4. **Timer** (#7): persisted start, status bar, Kanban Action Planner guard.
5. **Commands and UI** (#6, #8, #9, #10): Log practice modal, Practice plan / next view, Mastery and BPM modals with the rubric, Add note.
6. **Public API** (#11).
7. **Docs** (#12): user guide with screenshots; vault plugin note.
8. **Adversarial review** of the whole plugin before the first release; fix findings.

## Open questions
