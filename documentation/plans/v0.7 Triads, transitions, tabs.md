# v0.7: triads, transitions, tabs and scores

Goal: one release with music-notation 0.5 (#19, #21, #23, #24, #25, #26 there). Milestone "v0.7 Triads, transitions, tabs and scores".

## Triads as learning items (#55)

- Add a learning note: a triad's string set and inversion; frets from the library, shape "Triad" (the type's value), title `<chord> - Triad (strings 1-3, 1st inversion)`; an inversion gets the root-position note as a prerequisite when it exists.
- Triads command: a chord's or a key's triads on a string set, with the metronome; add any as a note.

## Easiest way between two chords (#57)

- On a pair note and in the chord change drill: "Easiest way": the second chord's voicings that move least from the first note's voicing, anchors and guides marked, tips; add one as a chord note.
- Smooth this progression: the chords of the note's ```chords block, in order, as the smoothest voicing sequence; add the missing voicings as notes.

## Tabs and scores (#15), playback (#31)

- `tab / `score blocks with the player; Insert a tab block command.
- Assets bundled in main.js (alphaTab, Bravura woff2, sonivox sf3): offline from the first use.
- Diagrams: the hover control bar (tap on mobile); in Obsidian the soundfont by default, a setting for the light synthesizer; settings for volume, sound, speed defaults; Play this chord or scale command.

## Import (#19) and export (#20)

- Import a score file (Guitar Pro 3–8, MusicXML, Capella): inline alphaTex or a link to the file (copied to the attachments folder, added to `sources`); at the cursor or in a new arrangement note.
- Import a text tab, Import a chord sheet (pasted), ChordPro files → ```chords.
- Export from a tab block: Guitar Pro 7, MIDI (next to the note), print.
