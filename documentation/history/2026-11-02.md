## v0.7: adversarial review of the fixes

- Review (separate agent): 0 high, 5 medium, 13 low; all addressed.
- Chord files: bracketed section labels (`[Verse 1]`) no longer make a file ChordPro (a bracket counts only when it holds a chord); UTF-16 without a BOM detected from its NUL bytes; a failed read says so in a notice.
- Plain-text tabs: a wider detector (two staff lines or more: blank staves, drum tabs, text after a line, three strings), alphaTex comments ignored; also for `score` blocks.
- Blocks are inserted after the properties or the code block the cursor is in, never inside (`regionEnd`); indentation before the cursor moves the fence to the margin. Imports and Insert a tab block share `insertBlock`.
- Linked score imports: file names cleaned of `#`, `|`, `^` and brackets (the wikilink worked only up to them); the copied file is trashed when the import fails later.
- `AlphaTabRuntime`: removes only the `alphaTab` its own script set; windows freed while loading drop that script's `alphaTab`, and freed windows are never tracked again; a failed load removes its tag; release steps each in their own try; our own script skips the version check, another plugin's needs a known, equal release; a spec ties the embedded alphaTab version to the library's `ALPHATAB_VERSION`.
- "Loading…" removed when a block is freed. Triad titles from one helper (`triadNoteTitle`) for the Triads command and Add a learning note.
- Notices: Immer added; a spec requires a notice (or a reason it isn't bundled) for every runtime dependency.
- Library 0.5.1: the `play` option's player function gets the window the diagram was drawn in (the plugin uses it instead of `activeWindow`; Obsidian draws blocks before moving them into a popout, so popout diagrams play through the main window's hidden player, which never closes: checked); a clicked slider loses Obsidian's focus ring (keyboard focus keeps it).
