Log practice now uses the same rules as the vault's learning skills: each session counts for the activity that lists its type, items get their minutes from their sessions, and logging the same session twice counts nothing twice.

- **The activity from `session_types`**: a session counts for the activity whose `session_types` lists its note type (for example `guitar-practice-sessions`). A type listed by two activities counts for neither. Archived activities are ignored. Without the Obsidian Starter Kit, and when no note uses `session_types`, the activity is found as before.
- **Log practice asks when no activity counts the session**: pick an existing activity (the closest names first), create a new one (the name comes from the **Activity name** setting, and you can change it), or log without an activity. Picking an activity adds the session type to its `session_types`; when other activities list the type, it is removed from theirs, and the dialog names them. A new activity is created only when you select **Log practice**, with the Starter Kit's activities type when you have it.
- **Minutes per item**: the session note lists the minutes each item got, in `practiced_minutes` (`"13 [[A Minor]]"`), when its session type has that property.
- **Item minutes come from the sessions**: an item's `time_spent` is computed from its session notes: its `practiced_minutes` value, or an even share of the session for older sessions that only list it. The minutes are never added to and never lowered on their own: when an item stores more, it stays and a notice says so.
- **The activity's minutes are never lowered on their own**: when an activity stores more minutes than its time entries and sessions give, a notice asks you to **Keep** the difference (a "Manual adjustment" time entry on the day the activity was created) or **Drop** it. Undo last practice log undoes that choice too.
- **Safe to log twice**: logging the same session again (same items, date, minutes and start time) uses its session note again, and a review is not counted twice. Without a start time from the timer or typed by you, only a session note created in the last 15 minutes is used again, so two real sessions stay two notes. Undo last practice log still undoes the first log.
- **Your activity choice stays**: Undo last practice log doesn't remove an activity it created or the session type it added to an activity.
- **Settings**: **Minutes per item** (`practiced_minutes`) and **Session types** (`session_types`) in the property names.
- **API**: `logPractice` takes `activity` (an activity note's name, or `null` for none) and returns `reused`, `createdActivity` and `activity.decision`.
